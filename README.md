# Formatting-Text-and-Organizing-Data

I built The Taste of Travel webpage as part of my learning journey with the Cisco Networking Academy. The page showcases the iconic Thai dish, Tom Yum Goong, using modern HTML5 standards.

Through this project, I learned how to configure the document's head section with proper UTF-8 encoding and SEO-friendly meta descriptions. On the layout side, I mastered semantic content hierarchy using <h1> through <h3> tags, emphasizing key ingredients with <strong>, and cleanly italicizing recipe steps using <em>. Finally, I developed advanced layout skills by building structured data tables, utilizing the colspan attribute to smoothly merge rows for cooking and preparation times.
